# ts-practice

Course exercises, book exercises and experiments from learning TypeScript. The project these feed is [ops-desk-agent](https://github.com/manojparvathaneni/ops-desk-agent).

## Layout

| Folder | What goes in it |
|---|---|
| `course-typescript` | "TypeScript: From First Steps to Professional" by Anjana Vakil, one folder per section |
| `course-javascript-projects` | Anjana Vakil's JavaScript projects course, implemented in TypeScript, one folder per section |
| `book-total-typescript` | Total TypeScript exercises, one folder per chapter |
| `book-programming-typescript` | Notes and small experiments from Programming TypeScript, one folder per chapter |
| `explore` | Friday exploration experiments and notes, one folder per topic |
| `scratch` | Anything else. Nothing here needs to work |

## How I use it

* One commit per session, with a message that names what I finished, for example "Course A section 3: arrays, objects and union types".
* No tags for daily work. The commit history is the progress record.
* `npm run check` type checks everything with strict settings.
* Nothing in this repo gets copied into ops-desk-agent before Jan 31, 2027.
